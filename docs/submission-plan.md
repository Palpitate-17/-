## 今晚按需巡检验收

1. 打开[私有智能体](https://gc.das-ai.com/agents/2113486599799504897)，输入：`请对 https://public-firing-range.appspot.com/ 执行网站巡检，仅检查预设的三个公开测试页面，并报告实际请求结果。`
2. 核对工具节点调用 `POST https://hengnao-authorized-scan.pages.dev/scan`，本轮返回新 `scan_id`、`execution_mode=on_demand`、`scan_status`、三个页面记录；结束节点报告应引用同一轮时间和范围。
3. 再输入白名单外的测试网址，确认路由拒绝、工具不被调用；用本地契约测试确认 API 也拒绝范围外网址。不要对该网址实际发出巡检请求。
4. 把首次成功的本轮 `scan_id`、执行状态、页数、发现和观察计数记入演示讲稿。计数取当轮实际结果，不沿用旧截图。

目前已发布智能体在用户输入时调用工具，**不是等定时任务产生结果**。若恒脑平台运行不稳定，先验收 Pages `/health` 和本机到 Pages 的带密钥 POST，再看工具调试状态。不要把本机临时隧道写成当前交付依赖。
